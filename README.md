🔍 Lost & Found Web Application

A web-based platform that helps people report lost items and find matched found items easily.
The goal of this project is to connect people who lost something with those who found it, in a fast and simple way.

🚀 Features

📢 Report lost items with details (name, category, location, date, description)

🧾 Post found items with images and information

🔎 Search and filter items by category, location, and date

🤝 Match lost and found items

📞 Contact option to connect the finder and owner

📱 Responsive design (works on mobile, tablet, and desktop)
